# Library system
It is a simple library system that allows managing
books, authors, and borrowers. The system provides functionalities to add, update, delete, and view records of books and authors. It also allows users to borrow and return books.

## Details
- **Books**: Each book has a title, author, ISBN, and availability status.
- **customers**: Each customer has a name, contact information, and a list of borrowed books.

## installation
1. Clone the repository: `git clone <repository-url>`
2. Navigate to the project directory: `cd library-system`
3. Install dependencies: `npm install`
4. Start the application: `npm start`
